Anatomía de una clase completa

public class Persona {
    // (1) ATRIBUTOS — siempre private (encapsulación)
    private String nombre;
    private int    edad;

    // (2) CONSTRUCTOR — mismo nombre, SIN tipo de retorno
    public Persona(String nombre, int edad) {
        this.nombre = nombre;   // this.atributo = parámetro
        this.edad   = edad;
    }

    // (3) GETTERS — leer atributos privados
    public String getNombre() { return nombre; }
    public int    getEdad()   { return edad; }

    // (4) SETTERS — modificar atributos privados
    public void setNombre(String nombre) { this.nombre = nombre; }
    public void setEdad(int edad)        { this.edad = edad; }

    // (5) MÉTODOS propios:
    public boolean esMayorDeEdad() { return edad >= 18; }
    public void cumplirAnyos()     { this.edad++; }

    // (6) toString:
    @Override
    public String toString() {
        return "Persona[" + nombre + ", " + edad + "]";
    }
}
// USO:
Persona p = new Persona("Ana", 21);
p.cumplirAnyos();
System.out.println(p);   // llama a toString()

Porcentajes encadenados (IVA, descuentos, recargos)

El concepto que más se atasca. Un porcentaje multiplica como (1 ± x), nunca se suma como número suelto. Sumar = añade céntimos; multiplicar = aplica el %. Para encadenar (recargo sobre un precio que YA lleva IVA), multiplicas factores uno tras otro.
// Un PORCENTAJE siempre MULTIPLICA como (1 +/- x). NUNCA se suma suelto.

double base = 45.0;

// SUMAR un % (IVA del 21%):  multiplica por (1 + 0.21)
double conIva = base * (1 + 0.21);          // 45 * 1.21 = 54.45

// RESTAR un % (descuento 5%): multiplica por (1 - 0.05)
double conDto = base * (1 - 0.05);          // 45 * 0.95 = 42.75

// ENCADENAR % sobre un valor YA modificado: multiplica factores seguidos
// "precio + IVA y LUEGO recargo 8% sobre ese total"
double total = base * (1 + 0.21) * (1 + 0.08);   // 45*1.21*1.08 = 58.81

// ERROR tipico 1: sumar el numero suelto (suma 8 centimos, no 8%)
//   base * 1.21 + 0.08      ->  54.53  MAL
// ERROR tipico 2: sumar los dos % al precio base (no encadena)
//   base * (1 + 0.21 + 0.08) ->  58.05  MAL (no es lo que pide el enunciado)

// Redondear a 2 decimales SIEMPRE al final:
total = Math.round(total * 100.0) / 100.0;

★ Patrón CSV completo (listas paralelas + la "y")

El patrón estrella de RA5. UNA lista por columna, los TRES filtros (cabecera / líneas mal formadas / fichero vacío), y el método unir() para la "y". La "y" va antes del último elemento; con un solo elemento NO aparece.
package ordinaria;

import java.io.BufferedReader;
import java.io.FileReader;
import java.util.ArrayList;

public class LeerCSV {

    public static void main(String[] args) {
        leerFichero("paises.csv");
    }

    public static void leerFichero(String fichero) {

        // UNA lista por columna (listas paralelas)
        ArrayList<String> paises    = new ArrayList<>();
        ArrayList<String> capitales = new ArrayList<>();

        try (BufferedReader lec = new BufferedReader(new FileReader(fichero))) {

            lec.readLine();                 // FILTRO 1: saltar cabecera

            String linea;
            while ((linea = lec.readLine()) != null) {
                String[] c = linea.split(",");      // separador EXACTO
                if (c.length != 4) continue;        // FILTRO 2: lineas mal formadas
                paises.add(c[0]);
                capitales.add(c[1]);
            }

            if (paises.isEmpty()) {                 // FILTRO 3: fichero vacio
                System.out.println("No hay datos en el fichero");
                return;
            }

            System.out.println("Paises en el fichero: " + paises.size());
            System.out.println("Nombres: " + unir(paises));
            System.out.println("Capitales: " + unir(capitales));

        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());   // NUNCA catch vacio
        }
    }

    // Une la lista con comas y "y" antes del ULTIMO elemento
    public static String unir(ArrayList<String> lista) {
        String r = "";
        for (int i = 0; i < lista.size(); i++) {
            if (i == 0)                      r = lista.get(i);
            else if (i == lista.size() - 1)  r = r + " y " + lista.get(i);
            else                             r = r + ", " + lista.get(i);
        }
        return r;
    }
}

RandomAccessFile (acceso aleatorio, CRUD por registro)

Cada registro tiene TAMAÑO FIJO → saltas directo al registro N. char=2 bytes, int=4, double=8, boolean=1.

// Registro: nombre(20 chars) + edad(int) = 20*2 + 4 = 44 bytes
static final int TAM_NOMBRE = 20;
static final int TAM_REGISTRO = (TAM_NOMBRE * 2) + 4;

public static void escribirNombre(RandomAccessFile raf, String n) throws IOException {
    for (int i = 0; i < TAM_NOMBRE; i++) {
        char c = (i < n.length()) ? n.charAt(i) : ' ';
        raf.writeChar(c);
    }
}
public static String leerNombre(RandomAccessFile raf) throws IOException {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < TAM_NOMBRE; i++) sb.append(raf.readChar());
    return sb.toString().trim();
}

// CREATE (añadir al final):
public static void nuevo(String ruta, String nom, int edad) throws IOException {
    try (RandomAccessFile raf = new RandomAccessFile(ruta, "rw")) {
        raf.seek(raf.length());
        escribirNombre(raf, nom);
        raf.writeInt(edad);
    }
}
// READ (registro N, cuentan desde 1):
public static void leer(String ruta, int num) throws IOException {
    try (RandomAccessFile raf = new RandomAccessFile(ruta, "r")) {
        long pos = (long) TAM_REGISTRO * (num - 1);
        if (pos >= raf.length()) return;
        raf.seek(pos);
        String nom = leerNombre(raf);
        int edad = raf.readInt();
        if (nom.charAt(0) != '*')   // '*' = borrado lógico
            System.out.printf("%d: %s, %d%n", num, nom, edad);
    }
}
// UPDATE:
public static void modificar(String ruta, int num, String nom, int edad) throws IOException {
    try (RandomAccessFile raf = new RandomAccessFile(ruta, "rw")) {
        raf.seek((long) TAM_REGISTRO * (num - 1));
        escribirNombre(raf, nom);
        raf.writeInt(edad);
    }
}
// DELETE (borrado lógico, marca con '*'):
public static void borrar(String ruta, int num) throws IOException {
    try (RandomAccessFile raf = new RandomAccessFile(ruta, "rw")) {
        long pos = (long) TAM_REGISTRO * (num - 1);
        raf.seek(pos);
        String nom = leerNombre(raf);
        raf.seek(pos);
        escribirNombre(raf, "*" + nom.substring(1));
    }
}

import java.util.Scanner;

public class t02ej1 {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        System.out.print("Cuántos dados vas a tirar? ");
        boolean entradaCorrecta = false;
        int numDados = 0;
        // Gestionamos que la entrada sea correcta; si no, insistimos
        while (entradaCorrecta == false) {
            entradaCorrecta = true;
            try {
                numDados = teclado.nextInt();
                if (numDados < 1) {
                    System.out.print("Entrada incorrecta. Vuelve a intentarlo: ");
                    entradaCorrecta = false;
                }
            } catch (Exception e) {
                System.out.print("Entrada incorrecta. Vuelve a intentarlo: ");
                teclado.nextLine();   // limpia el buffer tras el error
                entradaCorrecta = false;
            }
        }
        teclado.close();
        System.out.println("Has tirado " + numDados + " dados y ha salido lo siguiente: ");
        int contadorDeUnos = 0, contadorDeSeis = 0, suma = 0;
        for (int i = 0; i < numDados; i++) {
            int dado = (int)(Math.random() * 6) + 1;
            System.out.print(dado);
            if (i != numDados - 1)   // evita la coma tras el último
                System.out.print(", ");
            else
                System.out.println("");
            suma += dado;
            if (dado == 1) contadorDeUnos++;
            else if (dado == 6) contadorDeSeis++;
        }
        // Solo mostramos los contadores si no son cero
        if (contadorDeUnos != 0)
            System.out.println("En " + contadorDeUnos + " dados ha salido un 1");
        if (contadorDeSeis != 0)
            System.out.println("En " + contadorDeSeis + " dados ha salido un 6");
        System.out.println("La suma de todos los dados da " + suma);
        // posición respecto a la mitad (numDados*3 = mitad del máximo)
        if (suma > numDados * 3)
            System.out.println("Tu tirada está por encima de la mitad (" + numDados*3 + ")");
        else if (suma < numDados * 3)
            System.out.println("Tu tirada está por debajo de la mitad (" + numDados*3 + ")");
        else
            System.out.println("Tu tirada es exactamente la mitad (" + numDados*3 + ")");
    }
}

        String nTxtInvertido = "";
        // construimos el texto al revés

            nTxtInvertido += nTxt.charAt(i);
        // si el original y el invertido son iguales, es capicúa

            capicua = true;
        return capicua;
    }

            resultado.last();
            if (resultado.getRow() != 0) {   // hay empleados
                System.out.println("Hay " + resultado.getRow()
                    + " empleados en la oficina de " + ciudad + ". Sus datos son: ");
                resultado.beforeFirst();     // volvemos al inicio para recorrer
                while (resultado.next())
                    System.out.printf("%s, %s (%s)\n",
                        resultado.getString("lastname"),
                        resultado.getString("firstname"),
                        resultado.getString("email"));
                System.out.println();
            } else                            // oficina sin empleados
                System.out.println("La oficina de " + ciudad + " no tiene empleados\n");
        }
    }
}

🔑 Claves

  • ⭐ PATRÓN ESTRELLA del profesor para CONTAR y comprobar si hay resultados: rs.last() y luego rs.getRow(). Si da 0, no hubo resultados.
  • Por eso el PreparedStatement lleva TYPE_SCROLL_INSENSITIVE, CONCUR_READ_ONLY: para poder moverte con last()/beforeFirst().
  • Tras contar con last(), hay que volver con rs.beforeFirst() antes del while para recorrer desde el principio.
  • El JOIN cruza employees y offices por officeCode, filtrando por la ciudad. El ? se rellena con setString.
  • Tres casos cubiertos con if anidados: sin oficina (1ª consulta da 0), con oficina sin empleados (2ª da 0), con empleados.

Ej 2 — Mover empleados con UPDATE (RA9) ⭐

EnunciadoFunción que recibe dos ciudades y mueve TODOS los empleados de la oficina de origen a la de destino. Indica cuántos se mueven y cuántos quedan en destino. Comprueba que ambas oficinas existan.
✅ Ver solución del profesor
package examen2;
import java.sql.*;

public class Ejercicio2 {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/classicmodels";
        try (Connection conexion = DriverManager.getConnection(url, "admin", "1234")) {
            System.out.println("Conexión realizada con exito\n");
            moverEmpleados(conexion, "Tokyo", "Paris");
        } catch (SQLException e) {
            System.err.println("Error: " + e.getMessage());
        }
    }

    public static void moverEmpleados(Connection cnx, String origen, String destino) throws SQLException {
        System.out.println("Moviendo todos los empleados de " + origen + " a " + destino);
        String query = "SELECT officecode FROM offices WHERE city = ?";

        // PASO 1: ¿existe la oficina de ORIGEN? + obtener su código
        PreparedStatement sql = cnx.prepareStatement(query,
            ResultSet.TYPE_SCROLL_INSENSITIVE, ResultSet.CONCUR_READ_ONLY);
        sql.setString(1, origen);
        ResultSet resultado = sql.executeQuery();
        resultado.last();
        if (resultado.getRow() == 0) {
            System.out.println("No hay oficina en la ciudad " + origen);
            return;
        }
        resultado.absolute(1);                       // ir a la 1ª fila
        int codigoOrigen = resultado.getInt("officecode");

        // PASO 2: ¿existe la oficina de DESTINO? + obtener su código
        sql = cnx.prepareStatement(query,
            ResultSet.TYPE_SCROLL_INSENSITIVE, ResultSet.CONCUR_READ_ONLY);
        sql.setString(1, destino);
        resultado = sql.executeQuery();
        resultado.last();
        if (resultado.getRow() == 0) {
            System.out.println("No hay oficina en la ciudad " + destino);
            return;
        }
        resultado.absolute(1);
        int codigoDestino = resultado.getInt("officecode");

        // PASO 3: el UPDATE que mueve los empleados
        sql = cnx.prepareStatement("UPDATE employees SET officecode = ? WHERE officecode = ?");
        sql.setInt(1, codigoDestino);
        sql.setInt(2, codigoOrigen);
        int numero = sql.executeUpdate();            // nº de filas movidas
        System.out.println("Se van a mover " + numero + " empleados");

        // PASO 4: contar cuántos hay ahora en destino con COUNT(*)
        sql = cnx.prepareStatement("SELECT COUNT(*) FROM employees WHERE officeCode = ?");
        sql.setInt(1, codigoDestino);
        resultado = sql.executeQuery();
        resultado.next();                            // COUNT siempre devuelve 1 fila
        System.out.println("La oficina de " + destino + " tiene ahora "
            + resultado.getInt(1) + " empleados");
    }
}

🔑 Claves

  • El UPDATE ... SET officecode = ? WHERE officecode = ? mueve todos los empleados de una oficina a otra de golpe.
  • executeUpdate() devuelve el número de filas afectadas = cuántos empleados se movieron.
  • Para contar los de destino usa SELECT COUNT(*) + rs.next() una vez + rs.getInt(1) (columna 1).
  • rs.absolute(1) salta directo a la primera fila para leer el officecode (alternativa a first()).
  • Comprueba ambas oficinas con el mismo patrón last()+getRow()==0 antes de tocar nada.

Ej 3 — Clase Carta: Comparable + interfaz (RA7)

EnunciadoClase Carta (nombre, tipo, coste, descripción, ubicación). La ubicación inicial siempre es «Biblioteca» (no se pasa al constructor). Sobreescribe toString para imprimir con formato, y haz que al ordenar un ArrayList de Cartas se ordene por nombre. Define una interfaz Ubicacion con métodos cementerio(), biblioteca() y mano() que cambien la ubicación.
✅ Ver solución del profesor
package examen2;

// La interfaz con los 3 métodos que cambian la ubicación
public interface Ubicacion {
    public void biblioteca();
    public void mano();
    public void cementerio();
}
// ───────────────────────────────────────────────────────────
package examen2;

// implements Comparable (para ordenar) + Ubicacion (la interfaz nuestra)
public class Carta implements Comparable<Carta>, Ubicacion {
    private String nombre, tipo, descripcion;
    private int coste;
    private String ubicacion = "Biblioteca";   // valor inicial fijo

    public Carta(String nombre, String tipo, int coste, String descripcion) {
        this.nombre = nombre;
        this.tipo = tipo;
        this.coste = coste;
        this.descripcion = descripcion;
        // ojo: ubicacion NO se pasa, ya vale "Biblioteca"
    }

    @Override
    public String toString() {
        String t = "Nombre: " + nombre + "\n";
        t += "Tipo: " + tipo + "\n";
        t += "Coste: " + coste + "\n";
        t += "Descripción: " + descripcion + "\n";
        t += "Ubicación: " + ubicacion + "\n";
        return t;
    }

    // Comparable: ordena alfabéticamente por nombre
    @Override
    public int compareTo(Carta otra) {
        return this.nombre.compareTo(otra.nombre);
    }

    // Los 3 métodos de la interfaz Ubicacion
    @Override public void biblioteca() { this.ubicacion = "Biblioteca"; }
    @Override public void cementerio() { this.ubicacion = "Cementerio"; }
    @Override public void mano()       { this.ubicacion = "Mano"; }
}
// ───────────────────────────────────────────────────────────
package examen2;
import java.util.*;

public class Ejercicio3 {
    public static void main(String[] args) {
        Carta c1 = new Carta("Black Lotus", "Artefacto", 0, "Agrega 3 manás");
        Carta c2 = new Carta("Luna de Sangre", "Encantamiento", 3, "Tierras son Montañas");
        Carta c3 = new Carta("Ave del Paraiso", "Criatura", 1, "Vuela");

        ArrayList<Carta> lista = new ArrayList<>(List.of(c1, c2, c3));
        c2.cementerio();    // cambia ubicación
        c1.mano();

        Collections.sort(lista);   // usa compareTo -> ordena por nombre
        for (Carta c : lista)
            System.out.println(c);
    }
}

🔑 Claves

  • implements Comparable<Carta> obliga a definir compareTo: aquí compara por nombre con String.compareTo.
  • Collections.sort(lista) usa automáticamente ese compareTo para ordenar alfabéticamente.
  • La interfaz Ubicacion define 3 métodos que la clase Carta implementa para cambiar el atributo ubicacion.
  • Una clase puede implementar VARIAS interfaces a la vez separadas por comas: Comparable<Carta>, Ubicacion.
  • El atributo ubicacion se inicializa a «Biblioteca» en su declaración, por eso no va en el constructor.

Ej 4 — Dos lambdas con una interfaz (RA7)

EnunciadoCrea dos funciones lambda: una para el área y otra para el perímetro de un rectángulo. Ambas reciben dos double (los lados) y devuelven un double redondeado a 3 decimales.
✅ Ver solución del profesor
package examen2;

// Una sola interfaz funcional sirve para AMBAS lambdas
// porque tienen la misma firma: reciben 2 double, devuelven 1 double
public interface Rectangulo {
    double calcular(double a, double b);
}
// ───────────────────────────────────────────────────────────
package examen2;

public class Ejercicio4 {
    public static void main(String[] args) {
        // Definimos las dos lambdas usando la misma interfaz
        Rectangulo area      = (a, b) -> (double)(Math.round(a * b * 1000)) / 1000;
        Rectangulo perimetro = (a, b) -> (double)(Math.round((2*a + 2*b) * 1000)) / 1000;

        // Probamos que funcionan
        System.out.println("El area es: " + area.calcular(5.5457, 3.264));
        System.out.println("El perímetro es: " + perimetro.calcular(5.5457, 3.264));
    }
}

🔑 Claves

  • Las dos lambdas comparten interfaz porque tienen la MISMA firma (2 double → 1 double). Basta una sola interfaz funcional.
  • Una interfaz funcional = una interfaz con UN solo método abstracto. La lambda es la implementación de ese método.
  • Truco para redondear a 3 decimales: Math.round(x*1000)/1000.0 (multiplica, redondea a entero, divide).
  • (a, b) -> expresión es la sintaxis lambda: a y b son los parámetros, lo de la derecha es lo que devuelve.
